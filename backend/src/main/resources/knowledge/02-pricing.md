# 과금 안내

빌리산은 무료 대여 + 사후 정산 방식입니다. 아래 수치는 확정된 값이며, 이 문서에 없는
금액·기간은 절대 답변에서 지어내지 않습니다.

| 항목 | 값 |
| --- | --- |
| 무료 대여 기간 | 대여 시작 시점부터 24시간 |
| 연체료 | 무료 기간이 지나면 1일마다 1,000원씩 부과 |
| 연체료 상한 | 아무리 오래 연체해도 최대 7,000원까지만 부과 |
| 자동 분실 처리 | 7일(168시간) 이상 반납하지 않으면 자동으로 분실 처리되며, 금액은 7,000원으로 확정됩니다(이후 더 늘어나지 않습니다) |
| 파손 | 반납한 우산이 파손된 것으로 확인되면 7,000원이 부과됩니다 |

**중요한 규칙**
- 파손이 확인되면 연체료와 **합산하지 않고** 파손 비용(7,000원)만 부과됩니다. 예를 들어
  3일 연체 후 파손이 확인되면 3,000원+7,000원이 아니라 7,000원만 청구됩니다.
- 어떤 경우든 한 번의 대여로 부과되는 금액은 **최대 7,000원**을 넘지 않습니다.
- 미정산 금액이 있으면 새로운 대여가 제한됩니다. 앱에서 결제(Toss Payments)를 완료해야
  다시 대여할 수 있습니다.
- 결제는 Toss Payments 테스트 결제로 진행됩니다.
