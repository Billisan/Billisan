# 대여·반납 이용 흐름

## 대여

1. 키오스크에서 본인 확인이 완료됩니다.
2. 아래 조건을 모두 만족해야 대여할 수 있습니다.
   - 얼굴 등록이 완료되어 있어야 합니다.
   - 이미 대여 중인 우산이 없어야 합니다(동시 대여는 1개까지).
   - 미정산 금액이 없어야 합니다(있다면 앱에서 결제 후 이용 가능).
   - 대여소와 슬롯이 정상적으로 이용 가능한 상태여야 합니다.
3. 조건을 만족하면 대여 가능한 슬롯이 자동으로 지정되고 잠금이 해제됩니다.
4. 우산을 꺼내면 대여가 시작되고, 그 시점부터 무료 대여 기간(24시간)이 계산됩니다.

## 반납

1. 키오스크의 빈 슬롯에 우산을 넣습니다.
2. 반납 과정에서 우산 상태를 확인하는 절차가 함께 진행됩니다. 정상으로 확인되면 반납이
   완료됩니다.
3. 상태 확인이 애매하거나 이상이 발견된 경우, 반납 자체는 정상적으로 처리되지만 우산은
   별도로 관리자 확인을 거칩니다. 이 경우에도 사용자의 물리적인 반납 행위 자체는
   완료된 것으로 처리됩니다.
4. 관리자 확인 결과 파손으로 최종 판정되면 "과금 안내"의 파손 비용이 청구됩니다.

## 결제

- 정산이 필요한 경우 앱에서 확인할 수 있으며, Toss Payments 테스트 결제로 진행합니다.
- 결제가 완료되어야 새로운 대여가 가능합니다.
