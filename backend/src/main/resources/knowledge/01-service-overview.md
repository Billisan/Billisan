# 빌리산 서비스 개요

빌리산(Billisan)은 키오스크에서 본인 확인 후 우산을 대여·반납하는 서비스입니다.

- 이용을 위해서는 미리 발급된 계정으로 로그인하고 얼굴 등록을 완료해야 합니다. 앱에서
  직접 회원가입하는 기능은 없습니다.
- 키오스크에서 본인 확인이 완료되면 대여 가능한 슬롯 중 하나가 자동으로 지정되고,
  잠금이 해제되어 우산을 꺼낼 수 있습니다.
- 반납도 키오스크의 빈 슬롯에 우산을 넣는 방식으로 진행됩니다. 반납 시에는 우산 상태를
  확인하는 절차가 함께 진행됩니다.
- 한 사용자는 동시에 우산을 1개만 대여할 수 있습니다. 기존 대여를 반납하기 전에는 새로
  대여할 수 없습니다.
- 이용 방식은 무료 대여 + 사후 정산입니다. 정해진 무료 기간 안에 반납하면 비용이 들지
  않습니다(자세한 금액·기간은 "과금 안내" 문서 참고).
