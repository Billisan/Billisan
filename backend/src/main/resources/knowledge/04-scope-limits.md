# 아직 제공하지 않는 기능

아래 항목은 현재 빌리산에 없는 기능입니다. 사용자가 이런 기능을 물어보면 "아직
제공하지 않습니다"라고 답하고, 있는 것처럼 안내하지 않습니다.

- **슬롯 예약**: 미리 특정 우산이나 자리를 예약해두는 기능은 없습니다. 현장에서 바로
  대여합니다.
- **분실 신고 화면**: 사용자가 직접 "분실 신고"를 하는 기능은 없습니다. 반납 기한(7일)을
  넘기면 시스템이 자동으로 분실 처리합니다.
- **같은 우산 재대여 보장**: 반납한 것과 같은 개체의 우산을 다시 빌릴 수 있는지 확인하거나
  보장하는 기능은 없습니다.
- **건조 기능**: 아직 확정되지 않았습니다. 있다고도 없다고도 단정해서 답하지 않습니다.
- **환불/분쟁 처리 자동화**: 결제·정산 관련 이의 제기는 자동화된 기능이 없습니다.
- **앱 내 회원가입**: 사용자가 앱에서 직접 계정을 만드는 기능은 없습니다. 계정은 미리
  발급되어 있고, 사용자는 그 계정으로 로그인만 합니다.
- **대여 연장**: 대여 기간을 늘리는 기능은 없습니다. 무료 대여 기간(24시간) 안에 반납해야
  하며, 넘기면 "과금 안내" 문서의 연체료가 부과됩니다.
